## Official Starter Theme

Includes a basic theme setup with Bootstrap 5, SCSS, and Laravel Mix.

```bash
composer create-project open-function-computers-llc/wp-theme <theme-name>
```

View the [official starter theme](https://github.com/open-function-computers-llc/wp-theme) on GitHub.

## Community Starter Themes

Community starter themes offer a variety of different starting points for your next project.

Want to contribute a starter theme? [Open an issue](https://github.com/open-function-computers-llc/rad-theme-engine-docs/issues) or [submit a pull request](https://github.com/open-function-computers-llc/rad-theme-engine-docs/pulls)!

### Tailwind

A basic theme setup with Tailwind 4 and Laravel Mix.

```bash
composer create-project escherwd/rad-tailwind <theme-name>
```

View the [Tailwind starter theme](https://github.com/escherwd/rad-tailwind) on GitHub.
